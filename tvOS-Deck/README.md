# tvOS Deck

Apple TV / tvOS look for SteamOS Game Mode – Steam Machine (16:9, 4K), Steam Deck and Big Picture.
A theme for CSS Loader (Decky Loader).

## Install

1. Install [Decky Loader](https://decky.xyz) and the **CSS Loader** plugin.
2. Copy this folder to `~/homebrew/themes/tvOS-Deck` (or install “tvOS Deck” from CSS Loader's theme browser).
3. Quick Access (…) → CSS Loader → enable **tvOS Deck**.
4. Recommended: Steam *Settings → Customization → Home → Big Art Mode* for the Apple TV Top Shelf layout.

The font is loaded from this folder; keep the folder name `tvOS-Deck` or `tvOS Deck`.

## Options

| Option | Values |
| --- | --- |
| Focus Effect | Apple TV (Parallax) · Subtle · Off |
| Background | Graphite · Black (OLED) · Aurora (tvOS 26) |
| Font | SF Pro / Inter · Steam (Motiva Sans) |
| Footer | Minimal · Hidden · Steam Default |
| Keyboard Styling | Yes · No |
| Reduce Transparency | Yes · No |
| Colors | Accent color, toggle color |

## Notes

- The Steam menu and Quick Access are separate overlay windows and cannot blur the game behind them, so they use
  opaque glass.
- Inter © The Inter Project Authors, SIL Open Font License 1.1 (`fonts/Inter-OFL.txt`). SF Pro is not included;
  if it is installed on the device it is preferred automatically.
- Unofficial fan theme, not affiliated with Apple or Valve.
